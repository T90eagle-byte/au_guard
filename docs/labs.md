
# Лабораторные работы

Проект `au_guard` разрабатывался в рамках лабораторных работ №2–7 по дисциплине «Специализированные языки и технологии программирования».

Каждая лабораторная развивает предыдущую. Исходное состояние основного задания закреплено отдельным Git-тегом.

## ЛР2. Модульная архитектура, интерфейсы и ошибки

**Тег:** [lab02](https://github.com/T90eagle-byte/au_guard/tree/lab02)

Реализованы модель события, валидация, интерфейсы источника и обработчика, правила классификации, конфигурация и обработка ошибок через `errors.Is`, `errors.As` и `%w`.

**Дополнительное задание:** [e8e673d](https://github.com/T90eagle-byte/au_guard/tree/e8e673d)

Добавлены `ReplayModel` и `StubTool` — тестовые реализации интерфейсов без обращения к внешним сервисам.

## ЛР3. Потоковый CLI для событий JSONL

**Тег:** [lab03](https://github.com/T90eagle-byte/au_guard/tree/lab03)

Реализовано потоковое чтение JSONL из файла и stdin, строгое декодирование, ограничение длины строки, разделение stdout и stderr, коды завершения и тестирование CLI через внедрённые потоки.

**Дополнительное задание:** [f77ab32](https://github.com/T90eagle-byte/au_guard/tree/f77ab32)

Добавлен параметр `--timeout` и проверены соответствующие сценарии отмены.

## ЛР4. Ограниченный конкурентный конвейер

**Тег:** [lab04](https://github.com/T90eagle-byte/au_guard/tree/lab04)

Создан worker pool с ограниченными каналами, backpressure, сохранением порядка вывода и статистикой.

Обязательное самостоятельное задание — показатель `MaxActive`.

**Дополнительные тесты:** [6f47df3](https://github.com/T90eagle-byte/au_guard/tree/6f47df3)

Проверены backpressure и отмена обработки.

## ЛР5. Гонки, зависания и штатная остановка

**Тег:** [lab05](https://github.com/T90eagle-byte/au_guard/tree/lab05)

Исследованы гонки данных и зависания каналов. Добавлены тесты с Race Detector, согласованное завершение горутин и обработка `SIGINT`/`SIGTERM`.

Реализована остановка CLI при открытом stdin и заблокированном stdout.

Обязательное нагрузочное задание — обработка 500 событий при 8 workers и очереди размером 1.

## ЛР6. Безопасное чтение и атомарная запись файлов

**Тег:** [lab06](https://github.com/T90eagle-byte/au_guard/tree/lab06)

Реализован `ArtifactReader` с `os.Root`, проверкой путей, типов объектов и размеров до 64 КиБ.

Добавлена атомарная запись JSON-отчёта с правами `0600`.

Обязательное задание — `read_artifact` с расчётом размера и SHA-256.

## ЛР7. Безопасный запуск внешнего процесса

**Тег:** [lab07](https://github.com/T90eagle-byte/au_guard/tree/lab07)

Добавлен ограниченный запуск `/usr/bin/sha256sum -` через `exec.CommandContext`.

Реализованы ограничение времени, контролируемые stdout/stderr, строгая проверка результата и обновление отчёта.

## Как открыть нужную версию

После клонирования проекта:

```bash
git tag --list
git switch --detach lab04
```

Для возврата к последней версии:

```bash
git switch master
```

При просмотре дополнительных заданий используйте ссылки на соответствующие коммиты.

## Важное замечание

Теги `lab02`, `lab03` и `lab04` обозначают основные версии лабораторных. Их дополнительные изменения зафиксированы последующими коммитами, ссылки на которые указаны отдельно.

История Git сохранена без изменения первоначальных тегов.
