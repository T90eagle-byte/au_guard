
# Тестирование и воспроизводимость

## 1. Среда разработки

Проект разрабатывался на ALT Workstation 11.2 (ветка p11), архитектура x86_64.

Использовался пакет Go со строкой версии:

`go version go1.26.7-X:nodwarf5 linux/amd64`

Зафиксированная версия находится в `toolchain.txt`, параметры исходного стенда — в `evidence/lab01/`.

## 2. Быстрая проверка

В каталоге проекта:

```bash
go test -count=1 ./...
```

Опция `-count=1` отключает использование кешированного результата успешных тестов.

## 3. Статический анализ

```bash
go vet ./...
```

Команда обнаруживает некоторые подозрительные конструкции и ошибки использования языка.

Она не заменяет компилятор и автоматические тесты.

## 4. Race Detector

```bash
CGO_ENABLED=1 go test -race ./...
```

Для Linux x86-64 требуется работающий C-компилятор.

Race Detector обнаруживает гонки данных в реально выполненных сценариях. Успешная проверка не доказывает отсутствия гонок при всех возможных расписаниях.

## 5. Единый сценарий проверки

```bash
bash scripts/check.sh
```

Сценарий используется для контроля среды, форматирования, анализа, тестирования и сборки проекта.

Для воспроизведения исходного окружения важно точное совпадение версии Go с `toolchain.txt`. Обычный официальный Go того же номера может отличаться строкой версии от ALT-сборки.

## 6. Основные группы проверок

| Компонент | Проверяемое свойство |
|---|---|
| Events | Валидация, UTF-8, граничные значения |
| Config | Значения по умолчанию и допустимые диапазоны |
| Pipeline | Порядок, конкурентность, backpressure |
| CLI | Аргументы, потоки, коды завершения |
| Shutdown | Остановка по сигналам |
| Tools | Ограничение доступа и размера файлов |
| Hash | Внешний процесс, таймаут, формат SHA-256 |

## 7. Негативные эксперименты

В лабораторных работах временно вводились ошибки:

- Нарушение ожидаемого поведения функции.
- Замена `%w` на `%v` с потерей цепочки ошибок.
- Отсутствие закрытия канала `results`.
- Несинхронизированное изменение общего счётчика.
- Небезопасное открытие файла через путь.

Эксперименты выполнялись в контролируемой среде. После демонстрации дефектов корректные реализации восстанавливались.

## 8. Сохранение результатов

Каталог `evidence/` содержит сохранённые выводы проверок лабораторных.

Они служат дополнительными материалами, но не заменяют повторный запуск тестов на текущем состоянии исходников.

## 9. Проверка конкретной лабораторной

Например, для ЛР5:

```bash
git switch --detach lab05
go test -count=1 ./...
CGO_ENABLED=1 go test -race ./...
```

Для возврата:

```bash
git switch master
```

Полный сценарий `scripts/check.sh` рассчитан на зафиксированное окружение проекта.
